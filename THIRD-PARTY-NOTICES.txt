SPEECH-TO-TEXT MODELS — NOT bundled, downloaded on first run
  The Whisper speech-recognition models are NOT part of this distribution.
  They are fetched once, from the Hugging Face Hub, during first-run

    Whisper large-v3-turbo (CTranslate2 conversion)
      Repo: mobiuslabsgmbh/faster-whisper-large-v3-turbo
    Whisper large-v3 (CTranslate2 conversion)
      Repo: Systran/faster-whisper-large-v3

  Upstream model: OpenAI Whisper — MIT license
    https://github.com/openai/whisper
  The CTranslate2/faster-whisper conversions above are redistributions of
  those weights by Systran and mobiuslabsgmbh on the Hugging Face Hub.

  The model weights carry their OWN license, SEPARATE from this
  application's code license (PolyForm Noncommercial 1.0.0) and from the
  faster-whisper library license (MIT). This application neither bundles nor relicenses the model
  weights; use of the downloaded models is governed by the upstream
  Whisper (OpenAI, MIT) terms. See each model's Hugging Face page for the
  authoritative license of that specific conversion.

TEXT POST-PROCESSING COMPONENTS — NOT bundled, downloaded on demand
  (feature/punctuation-plus) Two OPTIONAL, experimental post-processing
  steps download their data only when the user turns them on and presses
  the download button in Settings; nothing here is part of the build.

    Autocorrect frequency dictionary — hermitdave/FrequencyWords, uk_50k
      (MIT). A plain "word count" list consumed by symspellpy.
      https://github.com/hermitdave/FrequencyWords
      NOTE: dict_uk (VESUM, brown-uk) is deliberately NOT used: it is a
      morphological dictionary (.dic/.aff), not a frequency list, and its
      tri-license (MPL-1.1/GPL-2.0+/LGPL-2.1+) is heavier than the MIT
      frequency list. If ever needed it can be kept as a separate
      user-downloaded data file without changing application code.

    Punctuator/ITN model — punctuators "pcs_47lang" (Apache-2.0), an ONNX
      model fetched via the punctuators package.
      https://github.com/1-800-BAD-CODE/punctuators
      The punctuators package itself is an OPTIONAL dependency (commented
      out in requirements.txt); when absent the feature degrades
      gracefully (the checkbox stays disabled) and the build is unaffected.

  These downloaded assets carry their OWN licenses (above), separate from
  this application's code license (PolyForm Noncommercial 1.0.0).
