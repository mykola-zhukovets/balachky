# Канон типографіки «Balachky»

Єдине джерело правди для розмірів, ваг, відступів і переносів тексту. Кольори і
родину шрифтів (Segoe UI класичний + золоті токени) НЕ чіпаємо — лише кегль,
вагу, міжряддя, відступи, wrap. База — Fluent 2 (Windows 11), адаптована до
наявних розмірів, щоб міграція була еволюційною.

Принцип ієрархії: розрізняй рівні **трьома важелями разом** — кегль + вага +
колір-роль, а не самим кеглем. Лише Regular (400) і Semibold (600); Bold та
курсив під забороною (курсив шкодить читабельності). Вирівнювання ліворуч.
Регістр речення (крім eyebrow-CAPS).

---

## 1. Шкала — 5 рівнів

Кольори — наявні токени з `theme.py`, без нових. Розміри збережено на поточних
значеннях коду (тому міграція = уніфікація, не рескейл).

| # | Рівень (`level`) | px / міжряддя | Вага | Колір-токен | Відступ до / після |
|---|---|---|---|---|---|
| 1 | `h1` — заголовок сторінки | 24 / 32 px | 600 | `TEXT_STRONG` (#FFFFFF) | зверху ≥24 (або край) · знизу 24 до контенту |
| 2 | `eyebrow` — напис над секцією | 12 / 16 px, CAPS, letter-spacing 2px | 600 | `GOLD_EYEBROW` (#FFC766) | зверху 24 (між секціями) · знизу 8–12 до першої картки |
| 3 | `block` — назва блоку/картки | 16 / 22 px | 600 | `TEXT_STRONG` | зверху 16 · знизу 4–8 до body всередині |
| 4 | `body` — основний текст, значення | 15 / 160% (≈24) | 400 | `TEXT_BODY` (#E6E5D1) | між абзацами 8 |
| 5 | `hint` — підказка, метадані, статус | 13 / 18 px | 400 | `TEXT_MUTED` (#D6CDB8) | 4 до свого поля (клеїться зверху) |

Правила розрізнення сусідів:
- 3↔4 однакова роль-різниця через **вагу** (600 vs 400) і кегль (16 vs 15).
- 4↔5 через **кегль + колір** (15 body vs 13 muted).
- Відступ НАД елементом завжди більший за відступ ПІД ним (групування
  близькістю, ~2:1): підказка тримається за своє поле, а не висить між сусідами.

Спец-варіанти (успадковують рівень, не нові кеглі):
- `pagesub` (підзаголовок сторінки) = рівень 5-подібний, 14/`TEXT_MUTED` — лишити.
- Бейджі черги (`done/busy/queued/error`) = 13px — рівень `hint` за кеглем.
- «Цифра статистики» на History — це НЕ `h1`, а власна велика цифра; винести
  окремий `stat`-варіант, щоб не ділити роль із заголовком сторінки.

Сітка відступів кратна 4px. Кегль ніколи не нижче 12px Regular / 13px на
масштабі 125% (перевірити, що caption не «розсипається»).

## 3. Правила переносу і ширини

1. **wordWrap=True на КОЖНОМУ QLabel довшому за 2 слова.** Без винятків для
   «коротких» — це страховка від обрізання при мінімумі 1000px. `spaced()` уже
   ставить wrap; для решти — явний `setWordWrap(True)`.
   Точки з аудиту без wrap, виправити:
   - meeting.py:318 `_proc_note` (довга примітка)
   - meeting.py:600 `saved` (шлях збереження — довгий рядок)
   - settings.py:708 `author`
   - onboarding.py:316 `title` (заголовок — ризик обрізання)
2. **Підказки багаторядкові, max-ширина ≈ 65 символів** (≈ 520–560px для 15px
   Segoe UI). Не placeholder замість лейбла (placeholder зникає при вводі).
   Довгі підказки — краще 13–15px `hint`, ніж дрібніше.
   - settings.py:68-88 `info_hint` — це QToolButton з plain-text tooltip;
     plain-text QToolTip НЕ переносить. Обгорнути текст у `<qt>…</qt>` (rich)
     або вставити переноси; стиль QToolTip (theme.py:92-98) додати max-width.
3. **Блоки тягнуться вширину** (layout stretch), не фіксована ширина.
   - vocab.py:110 діалог імпорту `setMinimumWidth(440)` без розтягування —
     дозволити рости; `vocab_cand_empty` (vocab.py:313-316) у AlignTop-боксі
     всередині ScrollArea має заповнювати колонку.
4. **Обрізання (elidedText) — лише для однорядкових значень** (шлях, назва у
   вузькому чіпі), НІКОЛИ для підказок і заголовків.
5. **Нічого не обрізається при ширині вікна 1000px** — критерій приймання.
   Перенос по словах, без розриву посеред слова, без justify.
6. Міжряддя: body/багаторядкові абзаци — 150–160%; однорядкові UI-рядки —
   1.43 (Fluent 20/14).

## 4. Реалізація — один source of truth

Замість розкиданих `font-size` по 5 механізмах (QSS-властивості, локальні QSS,
QFont pixel, QFont point, QPainter) — **одна властивість `level` у центральному
QSS** (`theme.py`). Кожен текстовий QLabel отримує `setProperty("level", …)`; усі
кеглі/ваги/кольори живуть в одному місці.

```python
# theme.py — додати в QSS блок «типографічні ролі»
QLabel[level="h1"]      { color: #FFFFFF; font-size: 24px; font-weight: 600; }
QLabel[level="eyebrow"] { color: #FFC766; font-size: 12px; font-weight: 600;
                          letter-spacing: 2px; }
QLabel[level="block"]   { color: #FFFFFF; font-size: 16px; font-weight: 600; }
QLabel[level="body"]    { color: #E6E5D1; font-size: 15px; font-weight: 400; }
QLabel[level="hint"]    { color: #D6CDB8; font-size: 13px; font-weight: 400; }
QLabel[level="stat"]    { color: #FFFFFF; font-size: 28px; font-weight: 600; }
```

(У коді кольори беруться з токенів `{TEXT_STRONG}` тощо через f-string, як уже
зроблено в theme.py — тут показано резолвлені значення для наочності.)

Використання:
```python
lbl.setProperty("level", "hint")   # замість локального font-size / setPixelSize
```

Правила імплементації:
- Старі властивості (`h1`, `strong`, `muted`, `eyebrow`) — залишити як
  сумісні аліаси на час міграції або перевести на `level` пофайлово за мапою §2.
- Розміри задавати в QSS px (логічні), Qt6 high-DPI масштабує сам на 125/150%.
  **Ніяких `setPointSize`/`setPointSizeF`** (pill.py:130 виправити на
  `setPixelSize(13)`), інакше рівень масштабується інакше за решту.
- Semibold — сім'я Segoe UI 600 через `font-weight: 600` у QSS; візуально
  перевірити, що не фолбечить у Bold. Bold і курсив не застосовувати ніде.
- Після зміни `level`/`property` у рантаймі викликати
  `style().unpolish(w); style().polish(w)`, щоб QSS перечитався.

Критерій готовності міграції: жодного `font-size`/`setPixelSize`/`setPointSize`
для тексту поза theme.py (grep чистий); одна властивість `level` покриває всі
5 рівнів; вікно 1000px — без обрізань.
