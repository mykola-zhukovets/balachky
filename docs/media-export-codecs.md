# Медіа-експорт нарад

Перевірено у Python/PyAV цього репозиторію (2026-07-16):

- `av.codec.Codec("libmp3lame", "w")` — доступний; MP3-експорт увімкнений.
- `av.codec.Codec("aac", "w")` — доступний; M4A-експорт увімкнений.

Застосунок перевіряє кодеки під час роботи: якщо інша збірка PyAV не має одного
із них, відповідний формат не пропонується. Мікс `mic.wav` + `sys.wav` вирівнює
доріжки від початку, нормалізує лише піки понад 1.0 і не допускає кліпінгу.
